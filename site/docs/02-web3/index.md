# Paradygmat Web3

Skoro wiadomo, *czemu* blockchain istnieje, pora na *jak* to działa od strony
dewelopera. Punkt wyjścia: co znika z Web2 stacku i co wchodzi na jego
miejsce. Odpowiada slajdom *Paradygmat Web3*
([PDF](https://github.com/matzayonc/stpl-slides/releases/download/latest/1_paradigm.pdf)).

## W skrócie

- **Portfel** zamiast serwera tożsamości
- **RPC** zamiast prywatnego API
- Stan **publiczny on-chain**, nie w bazie
- Read gratis, write z podpisem i opłatą
