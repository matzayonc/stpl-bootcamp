# Blockchain i Solana

Temat otwierający: skąd bierze się potrzeba blockchaina, czym jest sieć z
konsensusem BFT, co robi program on-chain i dlaczego wybór pada na Solanę.
Odpowiada slajdom *Dlaczego blockchain i Solana?*
([PDF](https://github.com/matzayonc/stpl-slides/releases/download/latest/0_why.pdf)).

## W skrócie

:::note Dlaczego blockchain?
- Prywatne serwery wymagają zaufania do właściciela
- BFT: zaufanie do kodu zamiast do ludzi
- Programy on-chain otwierają finanse bez pośredników
:::

:::note Dlaczego Solana?
- 50 000+ TPS i opłaty < $0.001 — BFT compute w skali
- Jeden layer — spójna platforma ekosystemu
:::
